Проект: Аналіз маркетингової ефективності рекламних кампаній Facebook

Контекст та мета проекту

Даний проект спрямований на проведення глибокого аналізу маркетингових даних (Facebook Ads) для відділу медіабаїнгу. Основна мета - оцінити ефективність використання бюджету, розрахувати показники окупності (ROMI) та виявити статистичні кореляції між витратами та отриманою цінністю для оптимізації майбутніх рекламних стратегій.

Основні вимоги та стек технологій

Мова програмування: Python 3.x.

Бібліотеки для обробки даних: Pandas.

Візуалізація: Matplotlib, Seaborn.

Середовище розробки: Jupyter Notebook (.ipynb).

Структура аналітичного звіту

1. Часовий аналіз та тренди (2021 рік)

Необхідно провести агрегацію даних за часовим показником для виявлення сезонності та динаміки витрат.

Побудова графіків щоденних витрат (Spend) та рентабельності інвестицій (ROMI).

Використання рухомого середнього (Rolling Average) для згладжування шумів та визначення реальних трендів.

2. Порівняльний аналіз кампаній

Оцінка продуктивності окремих рекламних інструментів.

Групування даних за назвою кампанії для порівняння загальних бюджетів.

Розрахунок та візуалізація сумарного ROMI для кожної кампанії з метою виявлення найприбутковіших напрямків.

3. Статистичний розподіл та волатильність

Аналіз стабільності результатів.

Використання діаграм "Box Plot" для оцінки розкиду ROMI та виявлення аномальних значень у кожній кампанії.

Гістографічний аналіз частоти значень ROMI для розуміння загального розподілу ефективності.

4. Кореляційний та регресійний аналіз

Дослідження взаємозв'язків між метриками.

Побудова матриці кореляції (Heatmap) для всіх числових показників.

Визначення факторів, що мають найбільший вплив на "Total Value".

Побудова моделі лінійної регресії між витратами (Spend) та цінністю (Value) для прогнозування масштабування.

Статус виконання завдань:

Дані завантажені з файлу facebook_ads_data.csv у DataFrame Pandas для подальшої обробки.

Виконано групування за днями за 2021 рік та побудовано графіки витрат і ROMI з використанням рухомого середнього.

Проведено агрегацію за кампаніями та створено візуалізації для порівняння загальних витрат і показників прибутковості.

Побудовано діаграми box plot для аналізу варіативності та розкиду щоденного ROMI у розрізі кожної кампанії.

Створено гістограму розподілу значень ROMI для оцінки загальної щільності результатів у датасеті.

Сформовано теплову карту кореляції та визначено статистичні зв'язки між числовими показниками і параметром total_value.

Реалізовано точкову діаграму з лінійною регресією через lmplot для візуалізації залежності отриманої вартості від рекламних витрат.
